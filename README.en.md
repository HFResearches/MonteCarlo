## 📌 About

**MonteCarlo** is an experimental C++ project designed to study stochastic
simulations applied to financial market data.

The goal is to generate possible price trajectories using random numbers and
analyze the results through **OHLC** data.

### OHLC

|     Field    | Meaning       |
| :----------: | ------------- |
|  🟢 **Open** | Opening price |
|  🔵 **High** | Highest price |
|  🔴 **Low**  | Lowest price  |
| 🟡 **Close** | Closing price |

---

## 🧮 Monte Carlo

The Monte Carlo method uses random sampling to generate possible scenarios.

```text
              ┌──────────────────┐
              │    Parameters    │
              └────────┬─────────┘
                       │
                       ▼
              ┌──────────────────┐
              │  Random Number   │
              │    Generator     │
              └────────┬─────────┘
                       │
                       ▼
              ┌──────────────────┐
              │  Monte Carlo     │
              │   Simulation     │
              └────────┬─────────┘
                       │
                       ▼
              ┌──────────────────┐
              │  Price Scenarios │
              └────────┬─────────┘
                       │
                       ▼
              ┌──────────────────┐
              │   OHLC Candle    │
              └──────────────────┘
```

> The simulation is not a guaranteed market forecast. It generates possible
> scenarios according to the assumptions defined by the model.

## 🔨 Build

Create the build directory:

```bash
mkdir -p build
```

Enter it:

```bash
cd build
```

Configure CMake:

```bash
cmake ..
```

Build the project:

```bash
cmake --build .
```

## ▶️ Running

After compilation:

```bash
./MonteCarlo
```

> The executable name depends on the configuration in `CMakeLists.txt`.

# ⚙️ Configuration

The current initial value is:

```cpp
constexpr double totalAssets{100.0};
```

The random distribution can be configured with:

```cpp
std::uniform_real_distribution<double>
    distribuir(-0.100, 0.100);
```

For example, to increase the variation range:

```cpp
std::uniform_real_distribution<double>
    distribuir(-1.0, 1.0);
```

---

# 🔬 How it works

The current implementation generates two random variations:

```text
d
│
├──────────────┐
│              │
▼              ▼
d1         totalAssets
│              │
└──────┬───────┘
       │
       ▼
 totalAssets + (d - d1)
       │
       ▼
   New price
```

The project is being developed to evolve from simple price variation generation
into a full price trajectory simulation.
